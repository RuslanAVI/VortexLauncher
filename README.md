# VortexLauncher beta
Лаунчер для Minecraft под Windows

# Что умеет

- Создавать отдельные профили для сборок. Каждый профиль лежит в своей папке и никак не пересекается с другими.
- Поддержка загрузчиков Vanilla, Forge, NeoForge и Fabric.
- Поддержка аккаунтов Offline, Microsoft и Ely.by.
- Поддержка каталога Modrinth: поиск модов, шейдеров, ресурс-паков и сборок.
- Продвинутое управление модами.
- Встроенный редактор конфигов прямо в лаунчере.

# Как установить?

1. Скачайте установщик: https://github.com/RuslanAVI/VortexLauncher/releases/download/Launcher/installer.exe
2. Запустите installer.exe. (Вас может попросить установить пакет .NET 10.0 — он нужен для работы установщика и самого лаунчера. Вас перебросит на сайт, и автоматически скачается файл для установки .NET 10.0. Запустите его и пройдите процесс установки. После завершения попробуйте снова запустить installer.exe).
3. В окне installer выберите пункт 1 или 2, в зависимости от того, куда вам нужно установить лаунчер.
4. После успешной установки лаунчер появится на рабочем столе и в меню «Пуск».

> **Важно:** При первом запуске установщика система Windows (SmartScreen) может выдать синее окно с предупреждением. Это происходит потому, что лаунчер является новой программой и пока не имеет платного цифрового сертификата от издателя. Это абсолютно нормально — чтобы продолжить, просто нажмите **«Подробнее»**, а затем **«Выполнить в любом случае»**.

# Нюансы

- Только Windows.
- Лаунчер находится в beta, так что возможны баги или недоработки.
- Из языков пока доступен лишь русский, в будущем добавится поддержка английского и украинского.
